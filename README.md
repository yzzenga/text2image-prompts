# 🎨 文生图 / 文生视频 提示词工坊

一款帮助用户快速组合、管理、复制 AI 文生图 / 文生视频提示词（Prompt）的网页工具。支持 Stable Diffusion、Midjourney、DALL-E、Sora 等主流 AI 生成模型。

---

## ✨ 功能特性

### 📄 基础版（`index.html`）
| 功能 | 说明 |
|------|------|
| 10 个分类模块 | 200+ 提示词标签，覆盖主流风格 |
| 多选标签 | 点击即可选择，自动合并生成完整提示词 |
| 中英文双语映射 | 中文标签 → 英文 Prompt 关键词 |
| 搜索过滤 | 快速定位目标标签 |
| 自定义追加 | 额外输入自定义描述附加到末尾 |
| 一键复制 | 复制到剪贴板即用 |

### 🚀 Pro 版（`prompt-workshop.html`）
| 功能 | 说明 |
|------|------|
| 17 个 Tab 模块 | 800+ 精细提示词标签，覆盖全方位描述维度 |
| 快捷脚手架 | 35+ 预制场景模板（含 Unsplash 预览图），一键应用完整场景描述 |
| 保存自定义模板 | 将当前组合保存为模板（名称/描述/可选预览图） |
| 模板管理 | 置顶显示、悬停删除、二次确认持久化删除 |
| 三级分类组织 | Tab → 子分类 → 标签项，精细化浏览 |
| 多行筛选导航 | 按画面风格、光影、构图等多维度快速筛选 |
| 三种复制模式 | 仅英文 / 仅中文 / 中英双语 |
| 负面提示词 | 开关切换 + 自定义输入负面描述 |
| 真实感增强 | 开关控制，自动添加自然皮肤纹理、真实光线描述和材质细节，减少 AI 感 |
| 已选标签预览 | 可单独删除已选标签 |
| 模块级徽章计数 | 显示各模块已选数量，支持一键清除 |
| 全局搜索 | 中英文同时匹配标签名和脚手架卡片 |
| 响应式布局 | 移动端自适应，底部固定结果面板 |

### 🎬 视频版（`video-prompt-workshop.html`）
| 功能 | 说明 |
|------|------|

| **竖屏运镜** | 竖屏跟拍、环绕、推拉、转场，适配 TikTok/Reels/Shorts |
| **AI 智能跟随** | 人物锁定、自动环绕、自动跟拍等 AI 辅助运镜 |
| **时间流逝** | 电控滑轨延时、大范围超延时、日转夜 Holy Grail、星空延时 |
| **画面参数** | 时长（短/中/长）、帧率（24fps/60fps/120fps）、分辨率（HD/4K/8K）、宽高比 |
| 三种复制模式 | English / 中文 / 双语 |
| 负面提示词 | 开关切换 + 自定义输入 |
| 真实感增强 | 自动添加自然皮肤纹理、真实光线描述 |
| 已选标签预览 | 可单独删除 |
| 模块级清空 | 每个 Tab 独立清空已选 |
| 全局搜索 | 中英文同时匹配标签和脚手架 |
| 响应式布局 | 移动端自适应 |

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| HTML / CSS / JavaScript | **纯原生**，零依赖、无构建步骤 |
| js-yaml | 通过 CDN 加载的 YAML 解析器 |
| 数据存储 | YAML 配置文件 + `localStorage`（自定义模板） |
| 运行方式 | 支持 `file://` 双击打开，或通过 HTTP 服务器运行 |

---

## 🚀 快速开始

```bash
# 方式一：直接打开（支持 file://）
# 双击 index.html / prompt-workshop.html / video-prompt-workshop.html 即可使用

# 方式二：通过 HTTP 服务器（推荐，避免跨域问题）
python3 -m http.server 8765
# 访问：http://localhost:8765/prompt-workshop.html
```

## 📦 数据文件

| 文件 | 用途 | 说明 |
|------|------|------|
| `prompt-data.yaml` | Pro 版提示词数据 | 内置 2956 行，17 个分类模块 |
| `video-prompt-data.yaml` | 视频版提示词数据 | 内置 738 行，11 个分类模块 |
| `prompt-data-self.yaml` | 自定义模板数据源 | **本地文件，不提交到仓库**（gitignored），可手动编辑 |
| `localStorage` | UI 保存/删除模板 | 自定义模板通过 UI 操作后同步持久化，与 YAML 数据合并加载 |

> **注意**：修改 YAML 数据文件后，需要手动将内容复制到对应 HTML 文件的 `<script type="text/yaml">` 标签内（嵌入式数据），或通过 JS 动态加载外部 YAML。
